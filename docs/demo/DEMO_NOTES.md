# Cove website demo

The MP4 is an edited walkthrough of real interactions with the local Cove application. Browser frames were captured at 8 fps within each chapter and encoded as 24 fps, 1920×1080 H.264 video. Captions are burned in; this version is silent. The opening and closing cards are editorial graphics. No chatbot replies were fabricated or substituted.

The video includes tracking guidance, visible references, a follow-up fallback, emotion-aware tone, Arabic, positive feedback, and an honest human-support response. The follow-up fallback is a visible quality limitation, not a demonstration of successful contextual answering. The reference dataset is synthetic and does not establish official store policy. This is not an accuracy benchmark.

Use the eight PNG screenshots or their ZIP archive in the presentation, PDF, and README. The SRT provides editable captions. The full video is approximately 100 seconds. No Colab run is required for this deliverable.

## Suggested README embed

Upload the MP4 to a GitHub release or another accessible video host, then link the thumbnail to that video. Keep screenshots under a docs/screenshots directory in the project. Never commit API keys or the .env file.
